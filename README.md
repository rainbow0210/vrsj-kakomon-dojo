# VR技術者認定試験 過去問道場（vrsj-kakomon-dojo）

[日本バーチャルリアリティ学会（VRSJ）](https://vrsj.org/events/seminar/)のバーチャルリアリティ技術者認定試験の過去問JSONを読み込み、情報処理技術者試験の「過去問道場」のようにスキマ時間で周回できる**単一HTML完結（外部CDN非依存）のWebクイズアプリ**です。

## 主な特徴

- **単一HTMLファイル完結（`index.html`）**: HTML / CSS / JavaScript を1ファイルに集約し、外部CDN・ビルドツール不要で動作します。
- **アプリ本体と問題データの分離**: 開催回ごとのJSONファイルを `data/` などに分けて管理でき、後から新しい年度・開催回を自由に追加できます。
- **ローカル直開き（`file://`）＆ Webホスティング両対応**:
  - ローカルで `index.html` を直接開いた場合は、ファイル選択（複数可）・フォルダごと読込・画面全体へのドラッグ＆ドロップで複数JSONと図表画像を一括読み込みできます（`examId` で重複管理・上書き更新）。
  - GitHub Pages や Webサーバー上で公開した場合は、同階層の `manifest.json` に列挙された問題JSONを自動ロードします。
- **図表・画像の読み込み＆拡大表示（Lightbox）対応**:
  - 問題本体（`images` / `image`）・選択肢（`choices[].image` / `choices[].images`）・解説（`explanationImages`）のすべてで図表表示に対応。
  - ローカル画像・相対パス・URL・Base64 Data URL に対応し、JSONと画像フォルダをまとめてドロップ・選択可能。
  - **問題IDによる自動紐付け**: JSONに画像パスを書いていない問題でも、`vrsj-28-app-05.png` や `vrsj-28-app-05_1.png` のように問題IDを含むファイル名で画像を読み込むと自動的に紐付きます。
  - **スクショ直接貼り付け（`Ctrl+V`）＆個別添付**: PDFを見ながらスクリーンショットを撮って演習画面にそのまま `Ctrl+V` で貼り付け可能（IndexedDBへ自動保存）。さらに「図入りJSON保存」で画像を埋め込んだ単一JSONとして書き出せます。
  - **タップで拡大（Lightbox）**: 200%ズーム、複数図の前後切替、白／暗背景の切替に対応（ダークモードでも黒線図表が視認しやすい白フレーム表示）。
- **マークシート／PDF併読モード対応**: 問題文や選択肢テキストが空文字（`""`）のデータや、`hasFigure: true` の図表問題にも対応。元PDFや読み込んだ図を見ながら大きな記号ボタンをタップして採点・履歴保存できます。
- **過去問道場風の出題・復習機能**:
  - 試験回（複数選択）・コース・分野での絞り込み
  - 出題モード切替：**順番通り** / **ランダム** / **間違えた問題・未解答のみ** / **ブックマークのみ**
  - 選択肢タップ時の即時正誤判定・解説表示・問題一覧ジャンプ・60分試験タイマー
  - 現在のフィルタ対象における解答済み数・正答数・正答率と**合格目安60%ラインバー**を上部常時表示
  - スマホ片手操作を意識した大きめボタン＆ダーク／ライトテーマ対応
- **学習履歴の自動保存 ＆ JSONエクスポート／インポート**:
  - `localStorage` に自動保存しつつ、`vr_kakomon_history_YYYYMMDD.json` として書き出し・読み込み（マージ統合／上書き復元）・リセットが可能。PCとスマホ間での学習履歴の引き継ぎに対応します。

## 図表・画像の読み込み方法

以下の4つの方法のいずれでも問題に図表を表示できます（併用可能）。

1. **問題JSONに `images`（または `image`）を記述する**
   ```json
   {
     "id": "vrsj-28-app-05",
     "number": 5,
     "question": "下図に示す光学系の構成として適切なものはどれか。",
     "images": [
       {
         "src": "data/images/vrsj-28-app-05.png",
         "alt": "光学系の構成図",
         "caption": "図1：光学系の構成"
       }
     ],
     "choices": [
       { "label": "ア", "text": "選択肢ア", "image": "data/images/vrsj-28-app-05_a.png" },
       { "label": "イ", "text": "選択肢イ" }
     ],
     "answer": "ア",
     "explanation": "解説テキスト（※AIによる補足）",
     "hasFigure": true
   }
   ```
   ※ `images: ["data/images/vrsj-28-app-05.png"]` のように文字列配列で簡潔に指定することも可能です。Base64 Data URL（`data:image/png;base64,...`）もそのまま使えます。
2. **JSONと画像を一緒に選択・ドロップ、またはフォルダごと読み込む**
   - ローカル直開き（`file://`）でも、JSONファイルと画像ファイル（PNG / JPG / WebP / GIF / SVG）を同時にドラッグ＆ドロップ、または「フォルダごと読込」で一括読み込みできます。
3. **問題IDと同名の画像ファイルを読み込む（自動紐付け）**
   - `vrsj-28-app-05.png` や `vrsj-28-app-05_1.jpg`、`vrsj-28-app-05-fig2.webp` のようにファイル名の先頭を問題 `id` にすると、JSONに `images` を書いていなくても自動でその問題に表示されます。
4. **演習画面で直接添付／クリップボード貼り付け（`Ctrl+V`）**
   - 演習中の問題画面で「図を添付」ボタンから画像を選ぶか、PDFのスクリーンショットをそのまま `Ctrl+V` で貼り付けられます（ブラウザの IndexedDB に自動保存）。「データ・履歴」タブの **「図入りJSON保存」** から図を埋め込んだJSONとして書き出すことも可能です。

## 使い方

### 1. ローカルで直接開く（インストール不要）
1. `index.html` をブラウザで直接開きます。
2. まずは **「デモ問題を1クリックで試す（通常1問＋図付きマークシート1問）」** ボタンで動作と図表拡大表示を確認できます。
3. 問題JSONと図表画像（複数選択可・フォルダ可）をボタンまたはドラッグ＆ドロップで読み込んで演習を開始します。

### 2. GitHub Pages / Webサーバーで使う
1. 問題JSONファイルを `data/` へ、図表画像を `data/images/` 等へ配置します。
2. `manifest.json` に問題JSONのパス配列を追記します。
   ```json
   [
     "data/vrsj_28_app.json",
     "data/vrsj_28_theory.json"
   ]
   ```
3. GitHub Pages を有効にしてアクセスすると、起動時に `manifest.json` から自動読み込みされ、図表画像もそのまま表示されます。

## 新しい開催回の過去問JSONを追加する方法

試験問題PDFと模範解答PDFから本アプリ用のJSONデータを作成する手順・プロンプト・JSONスキーマ仕様は [`requirements.md`](./requirements.md) にまとめています。

## ディレクトリ構成

```text
.
├── index.html                        # クイズアプリ本体（単一HTML完結・外部依存なし）
├── manifest.json                     # Webサーバー / GitHub Pages用の自動読込リスト
├── data/
│   ├── sample_demo.json              # 動作確認＆スキーマ参照用サンプル問題（通常1問＋図付きマークシート1問）
│   └── images/
│       └── demo_marksheet_fig.svg    # サンプル図表（HMD座標軸・回転3軸）
└── requirements.md                   # 開発仕様書・JSONスキーマ・PDF→JSON変換プロンプト集
```
